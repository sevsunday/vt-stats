Calibration tool quickref

Selecting

  • Click on a marker to select it
  • Shift+click to add to current selection
  • Click+drag on empty space to rubber-band select (rectangle)
  • Esc to deselect all

Moving

  • Drag a selected marker to move it (the whole selection moves together)
  • Arrow keys nudge selection by 1 px
  • Shift+arrow nudges by 10 px
  • Moved objects get stored as overrides in the config

Resetting

  • R reset selected markers to default projection
  • Reset ALL overrides button removes every saved override on this map

Saving

  • Auto-save: every drag is saved to localStorage immediately. Close the tab anytime; drafts survive.
  • Ctrl+S or the Save button writes the actual file. First save asks you to pick the configs folder (_map-analysis/calibration/configs/); subsequent saves are silent.

End of session

Run python _map-analysis/scripts/reprocess.py in a terminal to regenerate all overlay PNGs + the staging/ folder based on the latest configs.
