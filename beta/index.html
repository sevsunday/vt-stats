    How to join VSR Games

    Almost all VSR Vet Strat games are played on the devtest branch. To join these games, switch to that branch in Steam using a custom beta password:

    1. In Steam, right-click Battlezone and select Properties.
    2. In Properties, select Game Versions & Betas.
    3. At the bottom, in the Private Versions field, enter the code below and click Check Code.
      ••••••••
      The code is selected. Press Ctrl+C (Cmd+C on a Mac).
    4. Select the devtest branch and close the dialog window.
    5. Steam should auto-update and show the active version as devtest.
    6. The game version shown in the main menu should now match the version reported for live games, which you'll typically see on game watcher sites like GameWatch and the Discord watchbot.
    Hosting games? Set up port forwarding.
