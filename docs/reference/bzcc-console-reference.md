# BZCC console command reference

Generated by `scripts/extract_console_reference.py` on 2026-10-03 from BZCC 2.0.206.10 (executable SHA-256 `7c0889d8503b0f8cd696354ae72c3b8b6fb7eae899ffe1b4fbaf5b6230da82cc`). Console dump captured 2026-10-03.

Names come from the in-game listings; the executable's string table only cross-checks them. Bare commands with no namespace (such as `ls`) are listed only where observed. Explanations carry an evidence tier; an `inferred` tier is a reading of the name, not a verified behaviour.

## Using the console

- `ls` prints the namespaces: `iface`, `sys`, `profile`, `debug`, `dome`, `vid`, `bump`, `iam`, `multilanguage`, `keybind`, `console`, `options`, `ai`, `sky`, `audio`, `gameprefs`, `script`, `network`, `mission`, `inputbind`, `mesh`, `terrain`, `view`, `editor`, `shell`, `game`, `chrome`, `fog`, `rain`, `splat`, `sprites`, `sun`, `stars`, `control`, `scrap`, `status`.
- Typing a namespace or scope name on its own (`sky`, `network.session`) lists its members: `Cmd name` is a command, `name = value` is a variable, and `[sub]` is a nested scope you list the same way.
- Typing a variable name prints its value; typing it followed by a value sets it (`sun.angle 12` moves the sun to noon). Commands may take arguments in the same way.
- Statements end with `;`. `ls sky` and `help` are syntax errors ("Expecting ';'"); use the bare name instead.
- `console.log` toggles file logging. While on, every console line is written to the session log (`Battlezone <date>.log` in `My Games\Battlezone Combat Commander`, which may sit under OneDrive) as `DIAG| console:NNN |time|tick|text`.

Evidence tiers: **verified** = verified in-game; **engine** = engine text; **usage** = usage context; **inferred** = inferred from name, unverified; **unverified** = community knowledge, unverified.

## sky — atmosphere, fog, clouds

The per-map atmosphere. Everything here is saved in the map's `.sky` file (BZCC's editor documentation: "the SKY file contains all the information regarding atmosphere, weather, fog and effects, sun angle and time of day, sky graphics, ambient color, and visibility distance"). The `[NormalView]` fog and `[Light]` keys in the older `.trn` are no longer what the game renders; only the terrain material keys there still apply (see `terrain`). Values below were read on Europa Night (`vsreuronig`); Remnant reads fog `120 110 80`, range `300 -> 600`, visibility `600`, ambient `55 90 120`.

## sun — light, time of day

The directional light and the sun (or moon) sprite. The sun travels a fixed east-to-west arc: `angle 6` is sunrise on the east horizon, `12` is directly overhead, `18` is sunset in the west, with `period` hours per full cycle, in real time. The `color` alpha scales the light's brightness. Verified live on Remnant.

Example values below were read on `vsreuronig`.
