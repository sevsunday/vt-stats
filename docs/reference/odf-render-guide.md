## What is a Particle Render?

A Render is a Particle Effect that is rendered in the World. Many things can have particle Effects, most notably Weapons and Explosions, but they can also be attached to Objects. Renders are loaded through Object Definition Files, and are referenced by various ODF Properties. Similar to Classlabels, there are very specific Render Base and Simulate Base Classes that the game supports. This guide lists all the settings for each of these Classes.

## How to use Particle Renders

Render ODFs can be referenced from any location within the game's Asset tree. They can be part of existing ODFs, or separate in their own ODFs. ODF properties that point to Renders can specify a Render by the following format:

```
renderName = "myrenderfile.renderheader"
```

This example would point to `myrenderfile.odf` and header section `[RenderHeader]`. A render placed in an existing ODF is usually placed at the bottom, below all the other ODF Header sections. All the ODF Header rules listed in the ODF Documentation Guide still apply to Renders as well. Each Render should have its own unique Header. Unlike the GameObject's ODF Headers, however, the names of Render Headers can be whatever you like. Different file names can have Renders with the same Header name, and be referenced individually by their `filename.headername`.

You can also create a special ODF with only 1 Render item in it, and reference it directly by just the ODF name, if the `[Header]` matches the ODF name.

Render Bases are defined by:

```
[RenderHeader]
renderBase = ""
```

Valid `renderBase` names:

- `draw_null`
- `draw_bolt`
- `draw_emit`
- `draw_geom`
- `draw_light`
- `draw_multi`
- `draw_planar`
- `draw_sphere`
- `draw_sprite`
- `draw_static`
- `draw_tracer`
- `draw_trail`
- `draw_twirl`
- `draw_twirl_trail`
- `draw_wave`

`renderBase` can also reference another render item, the same way `renderName` is set. This can be used to make quick variations with only minor differences.

## What is a Particle Simulate?

Particle Simulate Classes define the physics behavior of the Particle Render Effects. Not all Particle Renders need a Particle Simulate, such as those attached to Ordnance or Objects via `renderName` or `effectName`. But any Render Item that is disconnected from that, such as generated by a `draw_emit`, or an Explosion's `particleClass`, needs a `simulateBase` to define its physics properties. The game will give a Console Error if a Particle is missing its `simulateBase`.

```
[RenderHeader]
simulateBase = ""
```

Valid `simulateBase` names:

- `sim_null` — stationary. Does not apply velocity on its own.
- `sim_chunk` — falls to the Ground and bounces with 50% velocity, and can have rotational velocity. Bounces off Ground but can clip through Collisions.
- `sim_dust` — spawns on the Ground, and can apply velocity.
- `sim_ember` — falls to the Ground and bounces with 50% velocity. Does not apply rotational velocity. Bounces off Ground but can clip through Collisions.
- `sim_spray` — falls to the Ground and bounces with 50% velocity. Does not apply rotational velocity. If height is below Collision height, sets height to the collision height, and cannot clip through Collisions.
- `sim_smoke` — can apply velocity.

## ParticleRenderClass

renderBase: `draw_null`

Particle Render is the base class for all Particle Effects.

- `minLOD = 0` — Minimum LOD setting, used with Graphics Option's Particle settings to cull particles.
- `maxLOD = 2` — Maximum LOD setting, used with Graphics Option's Particle settings to cull particles.
- `StartDelay = 0.0` — Time, in seconds, before this render starts to animate. This does not delay the `lifeTime`, only the `animateTime`. For Render Items this may only be supported on `draw_emit` and `draw_twirl_trail`.

## ParticleSimulateClass

simulateBase: `sim_null`

Root level Simulate base class. Particle Simulate Bases control the physics properties of Render items.

- `lifeTime = 1.0` — Time in seconds this Render lasts.
- `StartDelay = 0.0` — Time, in seconds, before this render starts to animate. Does not delay the `lifeTime`, only the `animateTime`.
- `maxCount = 128` — Maximum number of this particle that can be active on the screen at any given time before oldest ones get culled.
- `SimulateSoundEffect = ""` — Sound file played when this particle is emitted.

## EmitRenderClass

renderBase: `draw_emit`

Class tree: ParticleRender -> EmitRender

A Render that emits another ParticleRender item. Items spawned from this should have a `simulateBase` to define their movement.

- `emitName = ""` — The Render name to emit.
- `emitDelay = 1e30` — Time in seconds between emitting an instance of the Render. LOD level in Graphics Options Particle Setting increments this by * 2 or * 4.
- `emitDelayVar = 0.0` — Maximum variance in the `emitDelay`. Adds a random between 0 and `emitDelayVar` each emit. LOD scales this the same way as `emitDelay`.
- `emitPosVariance = "0.0 0.0 0.0"` — Maximum random position variance from the root position of the emitter.
- `emitVelocity = "0.0 0.0 0.0"` — Maximum random velocity variance.
- `emitVariance = "0.0 0.0 0.0"` — Maximum random directional variance for this Render's velocity.
- `emitInherit = "0.0 0.0 0.0"` — Percent of velocity inherited from the root emitter's velocity. 1.0 is 100%, but is not limited.

## MultiRenderClass

renderBase: `draw_multi`

Class tree: ParticleRender -> MultiRender

Renders multiple other Particle Render items simultaneously.

- `renderCount = 0` — How many Renders to add.
- `renderName1 ... renderName# = ""` — For each count, the Render name to generate.

## ColorRenderClass

Class tree: ParticleRender -> ColorRender

Color Render is the root class for all colored Particle Render items. It has no `renderBase` of its own.

- `textureName = ""` — Texture filename. File extension does not matter; the game internally converts it to `.dds`.
- `textureBlend = ""` — `"SourceMode DestinationMode TextureMethod"`.
  - Source/dest modes: `zero`, `one`, `srccolor`, `invsrccolor`, `srcalpha`, `invsrcalpha`, `dstcolor`, `invdstcolor`, `dstalpha`, `invdstalpha`, `srcalphasat`.
  - Texture methods: `decal`, `modulate`, `decalalpha`, `modulatealpha`, `decalmask` (unsupported), `modulatemask` (unsupported), `add`.
- `startColor = "0 0 0 0"` — Start color, RGBA.
- `finishColor = "0 0 0 0"` — Finish color, RGBA.
- `startRadius = 0.0` — Start radius.
- `finishRadius = 0.0` — Finish radius.
- `animateTime = 1e30` — Time to transition from start color/radius to finish color/radius.
- `useTerrainColor = 0.0` — Percent (0 to 1) of the terrain cluster color under the Render to blend with the current color.

## BoltRenderClass

renderBase: `draw_bolt`

Class tree: ParticleRender -> ColorRender -> BoltRender

Draws a series of trail segments with variance in direction between segments, a zigzagging trail.

Default: `animateTime = 0.1`

- `segmentLength = 0.0` — Length of each segment.
- `segmentVariance = "0.0 0.0 0.0"` — XYZ variance of each segment's direction.
- `textureRate = 0.0` — Rate which the texture can change per segment.
- `textureSpeed = 0.0` — UV speed of the texture along the trail.

## GeomRenderClass

renderBase: `draw_geom`

Class tree: ParticleRender -> ColorRender -> GeomRender

Draws a simple 3d geometry model. Supports rotation and transparency modes.

- `geomName = ""` — Model file name (`.xsi` or `.fbx`). `textureName` is applied to the UV mapping. The model can only be a single piece: no hierarchy, and only 1 texture on the entire surface.
- `InitialPitch`, `InitialYaw`, `InitialRoll = 0.0` — Initial orientation.
- `AddPitch`, `AddYaw`, `AddRoll = 0.0` — Added per second.
- `ForceDrawTransparent = true` — If true, draw with transparency. If false, draw opaque.
- `ForceDraw2Sided = true` — If true, draw two-sided. If false, hide back faces.

## LightRenderClass

renderBase: `draw_light`

Class tree: ParticleRender -> ColorRender -> LightRender

Draws a light source. `startColor` / `finishColor` alpha is light intensity. `startRadius` / `finishRadius` control the range of the light.

- `lightType = "point"` — `point` or `spot`.
- `attenuateConstant = 1.0` — Constant attenuation.
- `attenuateLinear = 0.0` — Linear attenuation.
- `attenuateQuadratic = 15.0` — Quadratic attenuation.
- `coneAngInner = 1.570795` — Inner cone angle for `spot`.
- `coneAngOuter = 1.570795` — Outer cone angle for `spot`.
- `coneFalloff = 1.0` — Cone falloff ratio. Used for `spot`.
- `lensFlare = true` — If false, doesn't create a sprite of `lightflare.tga` and `lighthalo.tga` at its origin. The size of the lens flare is controlled by the alpha of the color.

BZCC's shader forces the light to end at 0. Attenuation reference: Kc constant, Kl linear, Kq quadratic, R radius.

## PlanarRenderClass

renderBase: `draw_planar`

Class tree: ParticleRender -> ColorRender -> PlanarRender

Renders a texture along the ground surface. Usually used for explosion splash rings.

- `rotationRate = 0.0` — Rotation rate of the Render.

## SphereRenderClass

renderBase: `draw_sphere`

Class tree: ParticleRender -> ColorRender -> SphereRender

Draws a sphere. `latitudeBands` and `longitudeSegments` do not actually do anything on `draw_sphere`; it is hard coded to 16 and 32. Those ODF parameters only work on `ShieldEffect.odf`.

- `InitialPitch`, `InitialYaw`, `InitialRoll = 0.0`
- `AddPitch`, `AddYaw`, `AddRoll = 0.0` — Added per second.

## SpriteRenderClass

renderBase: `draw_sprite`

Class tree: ParticleRender -> ColorRender -> SpriteRender

A static sprite that does not rotate.

- `spriteCenter.x = 0.0` — Offsets the center of the sprite texture on X. 1.0 is 100%.
- `spriteCenter.y = 0.0` — Offsets the center on Y. 1.0 is 100%.

## StaticRenderClass

renderBase: `draw_static`

Class tree: ParticleRender -> ColorRender -> StaticRender

Draws randomized triangular polys in a sphere around the emitter.

- `innerRadius = 0.0` — Inner radius of the sphere.
- `outerRadius = 0.0` — Outer radius of the sphere.
- `emitDelay = 0.0` — Time in seconds between emitting particles.
- `emitDelayVar = 0.0` — Maximum random variance added to `emitDelay`.
- `staticTime = 1e30` — Overrides `lifeTime`, if present.
- `segmentTime = 0.0` — Overrides `animateTime`, if present.

## TracerRenderClass

renderBase: `draw_tracer`

Class tree: ParticleRender -> ColorRender -> TracerRender

Draws a static texture along a cross section of geometry.

- `tracerLength = 10.0` — Length of the tracer geometry.

## TrailRenderClass

renderBase: `draw_trail`

Class tree: ParticleRender -> ColorRender -> TrailRender

Draws a cross section trail geometry along the path of the emitter.

- `segmentTime = 0.0` — Overrides `animateTime` if specified. How long each segment takes to render.
- `textureRate = 0.0` — Rate the texture repeats across each segment.
- `textureSpeed = 0.0` — Speed the UV coordinates move the texture along the trail.

## TwirlRenderClass

renderBase: `draw_twirl`

Class tree: ParticleRender -> ColorRender -> TwirlRender

Draws a texture that can rotate and modulate with terrain.

- `rotationRate = 0.0` — Maximum random rotation that can be applied.
- `BottomInteractsWithTerrain = true` — If true, squishes vertically to avoid clipping through terrain.

## TwirlTrailRenderClass

renderBase: `draw_twirl_trail`

Class tree: ParticleRender -> ColorRender -> TwirlRender -> TwirlTrailRender

Similar to `draw_emit`, draws a trail of TwirlRender items behind it.

- `emitDelay = 1e30` — Time in seconds between emitting. LOD scales by * 2 or * 4.
- `emitDelayVar = 0.0` — Random 0..`emitDelayVar` added to `emitDelay`. LOD scales the same way.
- `emitPosVariance = "0.0 0.0 0.0"`
- `emitVelocity = "0.0 0.0 0.0"`
- `emitVariance = "0.0 0.0 0.0"` — Directional variance.
- `emitInherit = "0.0 0.0 0.0"` — Percent of inherited velocity.
- `emitLife = 1.0` — Time in seconds that each emitted TwirlRender lasts.
- `maxDist = 400.0` — Distance from camera at which it stops rendering.
- `maxRadii = -10.0` — Radius outside of camera view for it to skip rendering.
- `groupDelay = 0.1` — Delay between groups.

## WaveRenderClass

renderBase: `draw_wave`

Class tree: ParticleRender -> ColorRender -> WaveRender

Draws a flat semicircular wave.

- `waveAngle = 0.5` — Angle of the wave. Pi is fully circular.
- `waveDepth = 0.1` — How wide the wave is.
- `waveColorCenter = "255 255 255 255"` — Color at the center.
- `waveColorEdge = "255 255 255 255"` — Color at the edge.
- `waveTextureRepeats = true` — If true, repeat the texture per segment. If false, stretch it across the whole wave.
- `waveSegments = 4` — Number of segments.

## Explosion particles

`particleTypes`, `particleClass`, `particleCount`, `particleVeloc`, `particleBias`, and `particleInherit` belong to `[ExplosionClass]` and are documented in the ODF Documentation guide, not in this render guide. A `particleClass` value is a Render reference (`filename.header`).
