            About VT Stats

            VT Stats is a static dashboard for Battlezone: Combat Commander match statistics, built on top of VT's protobuf-based stats collector.

            Source repository
            sevsunday/vt-stats
            Dashboard, processing pipeline, and theme system.
            Stats collector (VT's repo)
            VTrider/statsgate
            In-game client that captures match data and writes the .binpb sessions this dashboard consumes.
            Multiplayer session API
            bz2api.js
            JavaScript library for querying live Battlezone 2: Combat Commander multiplayer session data.
            Build Order Log

            Every order this commander queued, finished, or cancelled, in the order it happened.

            Events
            • Queue — the commander ordered the unit. If something else is already building, this sits in line and is not paid for yet.
            • Build — the unit finished. The four numbers still show the scrap bank from when it was queued, not when it rolled off the line.
            • Cancel — the commander dropped it from the queue.
            The four numbers

            20|64|80|2

            cost | bank | cap | pools at the moment the unit was queued. Bank is what the commander had to spend (the engine takes the scrap on the next tick). Cap is storage (40 for a live recycler plus 20 per pool). Pools is how many extractors they held.

            The colored dots

            Scrap regenerates faster when the bank is low. The dot is the band at queue time:

            • Green — bank nearly full. Slowest regen.
            • Yellow — mid bank.
            • Red (can read orange on some themes) — bank low. Fastest regen; usually means the commander was spending as scrap came in.
            • Parallel — unused in VSR.

            Record your own stats

            Want your matches to show up here? Run the statsgate collector alongside Battlezone and share the resulting .binpb files.

            Prerequisites
            1. Subscribe to Extra Utilities 2 on Steam.
            2. Download the statsgate binaries .
            3. Unzip the contents anywhere you like.
            Additional info
            • Enter stats in the BZCC console to get a list of useful commands while the DLL is active.
            • The statsgate DLL self-terminates once BZCC closes — you'll need to re-run the launcher if you restart the game.
            Steps
            1. Start Battlezone.
            2. Run statsgatelauncher.exe to begin stats collection. No further action is necessary at this point.
            3. Each match is automatically saved as a separate .binpb file in one of:
              • Documents\My Games\Battlezone Combat Commander\statsgate (default)
              • Steam\steamapps\common\BZ2R\statsgate (if using novista launch option)
