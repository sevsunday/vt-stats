    How verification works

    Every coinflip and wheel spin here is locked to a future round of drand, a public network-wide randomness service. The host commits to a specific round number before that round's randomness exists, so they can't predict or rig the result.

    Verify a roll someone else did
    1. Grab the round number from their result (e.g. 28,970,906).
    2. Open the Provably Random panel here and expand it with the chevron.
    3. In Verify a roll, pick the tool (Coinflip / ShitWheel), paste the round number, and fill in the same inputs the host used (team labels for Coinflip, or the same items / roster order for ShitWheel).
    4. Hit Verify — you should see the same outcome.

    If the host shares the verify deep link from their result card, just open the link — the form auto-fills and runs verification on load.

    How it works
    • The host reserves a future drand round number at click time and shows it publicly in the result.
    • About 6 seconds later, the page fetches that round from two independent relays and rejects the result if their bytes disagree.
    • The page derives the outcome from those bytes using a fixed, public rule, so anyone who fetches the same round can recompute the same answer.
    Fallback mode

    If drand is unreachable, the page falls back to your browser's local random source. Those results carry an UNAUDITED watermark and can't be independently verified — wait for drand to recover (the Retry button) if trust matters.
