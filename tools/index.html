    Reset all tools?

    This will clear all in-memory state:

    • Manual roster (if any)
    • Wheel removals and last winner
    • Coinflip result
    • Map roll results
    • Team balonce commander config and manual swaps

    Toggles return to defaults (Auto mode, polling on, unlocked).

    Discard manual roster?
    Switching back to Auto will discard your manually curated roster (0 entries) and resume polling-driven roster updates.
    Heads up — this page doesn't persist

    The Lobby Tools page is purely client-side. Closing or refreshing this page will lose any manual changes beyond the auto-population features.

    Tools like Coinflip and the Player Wheel are designed to be run while screen-sharing in Discord. Auto-population features (e.g. live-lobby roster, Team Balonce) are consistent for everyone since they're based on live data from Rebellion.
